# HotelDB
## Technologies

- Backend: Node.js, Express, JavaScript, mssql / msnodesqlv8
- Database: SQL Server with Windows Authentication
- Frontend: React, Vite, plain CSS

## Setup and startup

Requires Node.js 22.12+, SQL Server Express and Microsoft ODBC Driver 17

Backend:
```powershell
cd backend
npm ci
npm start
```

Frontend:
```powershell
cd frontend
npm ci
npm run dev
```
